How it works

Every document follows the same six stages, so you always know what is happening.

  1. 1Upload
  2. 2Read
  3. 3Extract
  4. 4AI Analysis
  5. 5Review
  6. 6Export

What you can do

Read PDFs and images

Selectable PDF text is read directly. Scanned pages and images use text recognition that runs in your browser.

AI-assisted analysis

Identify the document type, names, dates, and reference numbers. Missing or uncertain values are flagged, never invented.

Review and correct

Check each field against the source text, then edit, add, or remove values without processing the document again.

Export your results

Download the extracted text and fields as plain text, JSON, or CSV files.

Supported files and privacy

Supported file types

  • PDF
  • JPG
  • JPEG
  • PNG
  • WEBP

Each file is checked before processing. Unsupported, empty, or damaged files are rejected with a clear message.

Your documents and privacy

Text extraction and recognition run in your browser, so your file itself is not uploaded for those steps.

When you request AI analysis, only the extracted text is sent through a secure server to the AI provider. You will be asked to confirm before that happens.

Uploaded documents are not stored permanently.
