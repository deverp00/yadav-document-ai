Processing guidance

  1. Use clear originals. Sharp, well-lit images give the most accurate text recognition.
  2. Prefer text-based PDFs. Selectable text is read directly and does not need recognition.
  3. Review every field. AI results can be wrong, so compare each value with the source text before exporting.
  4. Check what you send. AI analysis sends the extracted text to an AI provider, and you will be asked to confirm first.
